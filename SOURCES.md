| Source | Purpose | Licence / terms | Access |
|---|---|---|---|
| SSEN NaFIRS LV Faults | Primary outage incidents | CC BY 4.0 | https://data-api.ssen.co.uk/en/dataset/nafirs-lv-faults |
| SSEN Substation Data | District-level spatial matching | CC BY 4.0 | https://data-api.ssen.co.uk/en/dataset/ssen-substation-data |
| Open-Meteo | Historical and forecast weather | API data CC BY 4.0; attribution required | https://open-meteo.com/en/licence |
| OpenStreetMap | Optional power-infrastructure features | ODbL; attribution and database obligations apply | https://www.openstreetmap.org/copyright |
| Organising committee architecture parameters | Feeder/topology transformation and protection rules | Competition-provided; confirm final terms | Supplied during the challenge |

EAGLE-I and NOAA Storm Events are documented optional references but are not used by the core model because their US geography does not align with the primary UK outage data.
